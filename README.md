# 塔2 iOS 存档导出工具

Windows 10/11 x64 工具：将《杀戮尖塔 2》Steam 普通槽或 Mod 槽导出到 iOS Mod 槽位。

## 下载

从本仓库的 [Releases](../../releases) 下载最新版本的 `塔2存档导出工具-v1.3.0.exe`，无需安装 Python。

## 使用

启动 EXE，选择 Steam 存档目录、账号和一个或多个同类型槽位，然后导出 ZIP。普通槽与 Mod 槽不能混选；导出目标为 `Slay the Spire 2 Beta/default/1/modded/profileN`。

导出器只读取电脑存档，不修改原存档。使用及免费转发、修改版分发限制见 [EULA](EULA.md)。源码不在此下载仓库中。
